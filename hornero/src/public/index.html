Events

hornero_message
A message arrived
hornero_message_ack
A sent message was delivered or read
hornero_presence

hornero_reaction
Someone reacted to a message
hornero_poll_vote
Someone voted on a poll
hornero_group_update
A group's members or settings changed

Addressing

People are addressed by phone number with country code and no +.

Node-RED

No token needed: use a call service node for the services above, and an events: all node for the events.
